## 结论

- 被验：`app/index.html`（362 行全读）＋`app/server.py`（809 行 API/文案全读）＋`app/start.sh`（40 行启动文案），走查用户真实链路“填三路径→点开始监听→丢视频→等转写→收 md”。
- 主流程能走通，但**不算完：6 个 P0 阻断/严重迷路**。最断的三处：①首次三框全是代码词（input_root/ob_vault_root/Render），用户不敢填；②完成後 lineage 里没有输出路径，收 md 环断了（RENDER_ONLY 路径只藏在 worker 一句话里，PUBLISHED 路径只在 verdict 字符串里）；③失败原因只在“末个 run”一句话里，行级无原因无下一步，配无停止按钮，填错路径只能杀进程。
- 打回条件：任一 UX-P0 未 CLOSED 即打回（验收口径见下文，builder 无需再问用户即可执行＋qa 可重放）。
- 差哪（非阻塞）：8 个 P1 按用户价值排序＋6 个 P2 nice-to-have，用户故事＋验收口径见下文。

## P0 Blocking（不做不算完）

### UX-P0-1 我第一次打开不知道三个框该填什么
- 用户故事：作为第一次用的人，我打开页面只想填“视频在哪、笔记库在哪”，不想学 data_root/input_root/Render 是什么。
- 现状：三个 placeholder 全带代码变量名（`app/index.html:113,117,121`），vault 为空提示“空则只跑到 Render”无人能懂；data_root（外置测试目录）对用户无意义却占第一行；空状态三步只讲视频文件夹不讲 vault 为空会怎样。
- 验收口径（builder 直接做，无需问用户）：
  1. 三输入改为中文标签＋人话占位：视频文件夹（必填，如 /Users/你的名字/Movies/待转写）／Obsidian 库目录（选填，不填则 md 只存数据目录）／数据目录折叠进“高级”默认收起，框上禁出现 input_root/ob_vault_root/data_root/Render 英文词（变量名只留代码里）。
  2. 空状态（`#empty` 两种分支：无任务＋DB_MISSING）补一句 vault 为空的后果：“不填库也能转，md 在数据目录的 jobs 里，页面每行会给路径”。
  3. qa 重放：清空 localStorage＋新浏览器打开，5 秒内能说出哪框必填、vault 空会怎样；页面搜 input_root/ob_vault_root/Render 零命中（代码注释不计）。

### UX-P0-2 我点了开始不知道成功没，填错了也改不了
- 用户故事：作为用户，我点了开始监听想明确看到“监听中：哪个文件夹”，填错了想停下来改，不想杀进程。
- 现状：成功只靠顶部小锁＋一行 hint（`renderLock`），`btnStart` 常亮可重复点，重复点 409 报红字“监听已在运行”（正常态被标红）；运行中改输入框无任何提示（实际不生效，需重起）；无停止按钮，换文件夹＝杀 server 重起；`refresh()` 的 DB_MISSING 分支会覆盖掉刚成功的提示。
- 验收口径：
  1. 成功常驻条：监听中时输入区上方固定一条绿条“监听中：{input_root}，把视频丢进去即可”，轮询不覆盖不消失；`btnStart` 置灰禁用并文案变“监听中…”，新增 `btnStop`（POST /api/stop 或等价，停监听＋停 worker 轮询，锁回“未监听”）。
  2. 409 改人话非红：重复点开始回“已经在监听同一文件夹，无需重复操作”，样式走 ok/warn 不走 err。
  3. 运行中三输入只读（或改后黄条提示“修改下次启动生效，当前监听 {input_root}”）；`refresh()` 禁止用状态文案覆盖成功条。
  4. qa 重放：启动→绿条常驻＋按钮置灰；重复点→黄字非红；改输入→黄条提示；点停止→锁回未监听＋可换路径重起，全程不杀进程。

### UX-P0-3 转写完成了我找不到 md 在哪
- 用户故事：作为用户，状态变完成後我想在点击的那一行直接看到 md 路径并能复制/打开，不想翻终端和 verdict 字符串。
- 现状：选中 run 谱系只有 run_id/source_id/状态/更新/创建（`renderLineage`），无输出路径、无 verdict、无耗时；PUBLISHED 路径拼在 verdict 里、RENDER_ONLY 路径拼在“停在 Render…md 见 …”里，只在 worker 末行一句话显示且仅保留末个；表格状态靠 `（worker）` 后缀透出终态，用户看不懂。
- 验收口径：
  1. `renderLineage` 必显四行：输出 md 路径（PUBLISHED 给 vault 内路径，RENDER_ONLY 给数据目录 render 路径，FAIL 给“未产出”）、人话结论（如“已存入你的笔记库”）、耗时（created_at→updated_at）、失败见 UX-P0-4；路径旁给“复制”按钮（navigator.clipboard，失败则 select 可手动拷）。
  2. runs 表新增“输出”列或行内链接：有 md 即显示“打开位置”（file:// 链接或复制按钮），无 md 显示“—”。
  3. vault 映射预览：开始监听后 hint 区一行“视频 A/B/C.mp4 → 库内 笔记/X.md 式样”（调已有 resolve_canonical 预览，不落盘），用户点开始前就知道会落哪。
  4. qa 重放：各造 1 个 PUBLISHED＋1 个 RENDER_ONLY，点行即见可复制路径；RENDER_ONLY 路径真实存在；全文搜“（worker）”零命中。

### UX-P0-4 转写失败了我看不到为什么、下一步干什么
- 用户故事：作为用户，失败时我想在那一行看到人话原因＋能点的下一步（重试/换文件/看详情），不想猜。
- 现状：FAIL/PUBLISH_BLOCKED 的 verdict（源文件不存在／转写失败／schema 门拒绝／镜像映射失败／Publish 被拒等）只进 `worker.processed`，页面仅展示末个的 run_id/state/verdict 一句话；行级状态 FAIL 无原因；lineage 无 verdict；无重试入口。
- 验收口径：
  1. 行级失败必显：runs 表失败行状态列中文“失败”，lineage 区红块显示“人话原因＋下一步”二段式（如“视频里没检测到语音→换一个有声音的视频再试”；“库目录不可写→检查库路径权限后点重试”），原因文案禁裸抛异常类名（如 `ArchiveError` 必须配一句人话）。
  2. 每失败行给“重试”按钮（本期最小：调后端单 run 重跑或给一条复制即用的操作指引，二选一但必须可点击闭环，不只给文字）。
  3. qa 重放：各造源缺失／mlx 缺失／vault 不可写三类失败，每行点开均有红块原因＋下一步＋重试可点；刷新后原因不丢（读后端 verdict，不读内存末行）。

### UX-P0-5 等转写时我以为卡死了
- 用户故事：作为用户，长视频转几分钟时我想看到“在转哪个文件、到哪一步、转了多久、心跳在走”，不想对着不动的 0% 发呆。
- 现状：`#progress` 只有“正在{stage}：{filename}（已用时 Xs）· 排队 N/已完成 M”＋总体 done/(pending+done) 条；stage 词“标准化/渲染”无人懂；无单文件百分比、无剩余估计、无心跳（5s 轮询无变化时与死机无异）；pending 语义（QUEUED AUTO 前缀过滤＋内存去重）与表行数对不上时更显“卡死”。
- 验收口径：
  1. 进度文案改人话四段＋心跳：“正在听写 {filename}（第 X 步/共 5 步：发现→听写→整理→成稿→入库）· 已用时 Ys · 心跳 Zs 前更新 · 排队 N/已完成 M”；转写中/整理中等价映射禁出现“标准化/渲染”裸词。
  2. 进度条双层或双文：总体条保留，另加当前文件不定式动画（indeterminate）或按阶段步进（发现 10%→听写 60%→整理 75%→成稿 90%→入库 100%，文案注明“步骤进度非精确百分比”防误解）。
  3. 停滞兜底：单阶段超 60s 无变化自动追加一句“还在跑，长视频请勿关闭页面”。
  4. qa 重放：60s 真实切片转写全程录屏，心跳每次 5s 必变；文案搜“标准化/渲染”零命中；排队 2 个时完成 1 个条必前进一格。

### UX-P0-6 报错说的是开发黑话
- 用户故事：作为用户，报错时我想看到“哪错了＋我要点什么”，不想看到 stage0bench/mlx_whisper/PRECHECK 这类词。
- 现状：mlx 缺失 400 文案让用户“用 stage0bench venv 重起（./app/start.sh 会优先选）”（`server.py:737-740`＋`start.sh:11-23`）；vault 提示 Render；浏览失败“卷判定失败”；409 红字；引号自动去 detenido（`normalize_path`）前端无回显，用户不知粘贴的引号已被处理。
- 验收口径：
  1. 建人话错误表（前端＋后端同文）：mlx 缺失→“转写环境没就绪：请按文档第 X 步用自带一键启动重开，再点开始监听”＋给 start.sh 按钮/命令一键复制；路径不存在/非绝对/无权限/非本地盘→“第 X 个框的路径有问题：{路径} {不存在/须为绝对路径/无权限/仅支持本机硬盘}，点浏览重选”；401/409/500 通用人话兜底禁裸抛 code。
  2. 粘贴去引号回显：输入框失焦若首尾引号被去，框下黄字一句“已自动去掉首尾引号”。
  3. qa 重放：分别触发 mlx 缺失/路径不存在/相对路径/无权限目录/重复启动五类，截图文案无 stage0bench/mlx_whisper/PRECHECK_MLX_MISSING/Render/input_root 裸词（命令按钮内的 start.sh 例外，需配中文说明）。

## P1（重要，按用户价值排序）

### UX-P1-1 失败的那个视频我想点一下就能重跑
- 用户故事：作为用户，失败行点“重试”就只重跑那一个，不重起监听不重转别的。
- 验收口径：失败/PUBLISH_BLOCKED 行各有“重试”按钮；点后该行回“排队中”，成功则终态更新、失败则原因更新；连点两次不产生重复任务（幂等：同 run_id 去重）；qa 用源缺失→补文件→重试 PUBLISHED/RENDER_ONLY 全绿。

### UX-P1-2 重起后已转好的不想再转一遍
- 用户故事：作为用户，服务重起后已产出 md 的视频自动跳过，只转新增的。
- 验收口径：启动时按 source content_identity＋输出 md 存在性跳过已完成（不只靠内存 `_worker_done`）；进度“已完成 N”重起不归零（读 DB/磁盘，不读内存）；qa：转完 2 个→杀 server 重起→pending=0、done=2、无重复 whisper_calls。

### UX-P1-3 没填库时我想知道 md 落在了哪里
- 用户故事：作为用户，不填 Obsidian 库也能转，且页面明确告诉我 md 在数据目录的哪。
- 验收口径：vault 为空启动时绿条追加“未填笔记库，md 只存数据目录”；RENDER_ONLY 行 lineage 输出路径真实可复制且文件存在；qa：空 vault 转 1 个，点行即得存在路径。

### UX-P1-4 选文件夹时我想确认里面有没有视频
- 用户故事：作为用户，点浏览时能看到该目录下视频文件数/前几个文件名，防选错空目录。
- 验收口径：浏览弹窗每目录行追加“（N 个视频）”计数（按扩展名 mp4/mov/mkv/m4a/mp3/wav 统计，只读不递归或一层，1000 上限内）；空视频目录黄字“该目录无视频文件，选了也转不出东西”；qa：空目录与有 3 个视频目录各截一图。

### UX-P1-5 长视频转之前想先知道要等多久
- 用户故事：作为用户，超过 10 分钟的视频开始前就想看到“很长、分段跑、别关页面”的提示。
- 验收口径：浏览/input 失焦时若目录含 >600s（有 sidecar/时长缓存则用，无则按 >500MB 估算并注明估算）视频，提示“检测到长视频 X 个，转写可能超 Y 分钟，分段进行请勿关闭页面”；转写中文案注明“长视频分段中”；qa：600s 上下各 1 个用例提示出现/不出现。

### UX-P1-6 有结果时我想被提醒一下
- 用户故事：作为用户，转完/失败时页面弹个提醒，我切别的窗口也能知道。
- 验收口径：done/failed 计数变化时页内 toast（绿/红，3s，含文件名＋点行跳转）；初次提醒前申请 Notification 权限（拒绝则只页内 toast，不报错）；qa：后台切走转完 1 个，回来可见 toast＋计数＋行。

### UX-P1-7 路径填错点开始前就告诉我
- 用户故事：作为用户，输完路径不用点开始就知道对不对。
- 验收口径：三输入失焦即验（绝对路径/存在/是目录/本地盘，复用 /api/browse 逻辑只读），错即框红＋框下人话一句；全对开始按钮才高亮（仍可点，防 race）；qa：相对路径/不存在/文件非目录三类失焦即红，正確路径即绿。

### UX-P1-8 状态词我想看中文
- 用户故事：作为用户，状态只想看排队中/听写中/已完成/失败，不想看 QUEUED/PUBLISHED（worker）。
- 验收口径：建状态映射表（QUEUED→排队中，发现/听写中/整理中/成稿中/入库中，PUBLISHED→已入库，RENDER_ONLY→已成稿未入库，FAIL/PUBLISH_BLOCKED→失败/入库受阻），全页英文状态词零裸露；色板沿用绿/橙/红；qa：全状态截图＋全文搜 QUEUED/PUBLISHED/RENDER_ONLY/（worker）零命中（代码内除外）。

## P2（nice-to-have）

### UX-P2-1 磁带英文词想知道意思
- 用户故事：作为用户，悬停 Source/Run/Raw…能看到一句中文说明，或默认收起不挡路。
- 验收口径：每 seg 加 title/悬停中文（如 Source=发现的视频，Raw=原始听写…）或折叠默认收起；qa：悬停截图。

### UX-P2-2 想知道支持哪些格式
- 用户故事：作为用户，空状态就想看到“支持 mp4/mov/mkv/mp3/wav”，不支持的丢进去有提示。
- 验收口径：空状态补支持格式一行；worker 遇不支持扩展名记人话 verdict“暂不支持 {ext}，换 mp4/mov/mp3/wav 再试”；qa：丢 1 个 .txt 即见该提示。

### UX-P2-3 刷新按钮别骗我
- 用户故事：作为用户，点了刷新想等数据回来才看到“已刷新”。
- 验收口径：`btnRefresh` 点后文案“刷新中…”禁用，fetch 全回后才“已刷新”＋时间；自动轮询保留；qa：断网点刷新保持“刷新中”不谎报。

### UX-P2-4 小窗口和键盘也能走完
