# Video2Obsidian｜本地视频自动转写入库工具

把本地视频文件夹变成 Obsidian 笔记：本地 Whisper 转写 → 专业词修正 → 自然分段 → 目录镜像 → 安全写入 Obsidian 库 → 源视频归档。全程本地运行，零 API 成本。目标设备：Apple Silicon Mac。

![本地控制台首页](docs/screenshots/console.png)

## 快速开始

```bash
./app/start.sh
# 打开 http://127.0.0.1:8765/
```

1. 填**视频文件夹**（必填）、**笔记库目录**（选填，不填也能转）、数据目录（高级里，默认外置）。
2. 点**开始监听**，把视频丢进文件夹。
3. 在任务列表看进度，完成后点行看笔记正文，一键**在访达中打开** / **在OB中打开**。
4. 术语听错了？在**词汇**区加“错词→正词”，新转写自动应用，还能一键重跑存量。

需要转写环境：Python 3.12 + `mlx-whisper` + `ffmpeg`（`start.sh` 会自动找本机已配好的 venv，缺环境会明确提示）。

## 仓库结构

- `app/` — 本地 Web 控制台（`server.py` stdlib-only 后端、`index.html` 单文件前端、`start.sh` 一键启动）
- `src/stage1~12/` — 流水线引擎：单视频 ingest＋来源证明、候选/去重、标准化/渲染、Canonical 发布、监听扫描、路径镜像、Prompt/词库、VAD/分块、段落、归档、LaunchAgent、菜单栏状态
- `docs/` — 开发计划（`pm/`）、代码评审（`review/`）、QA 报告（`qa/`）、交接（`handoff/`）、模型账本（`model/`）
