# 使用说明

目标读者：第一次用 Video2Obsidian 控制台的人。
为什么不在 README 讲完：这里是完整操作路径，README 只保留最短开始方式。

## 1. 启动

在仓库根目录执行：

```bash
./app/start.sh
```

打开：

```text
http://127.0.0.1:8899/
```

端口默认 `127.0.0.1:8899`，只监听本机；如需换端口，用环境变量 `V2O_PORT` 覆盖（`app/start.sh` 会透传给 `app/server.py`）。

## 2. 三个目录怎么填

- **视频文件夹（必填）**：要监听的本机绝对路径。从访达复制的带引号路径可以直接粘贴，会自动去引号。也可以用页面内置的目录浏览只选目录。
- **笔记库目录（选填）**：你的 Obsidian 库目录。不填也能转写，此时流程停在“成稿”，不写入任何现有库。
- **数据目录（高级，选填）**：中间产物和数据库的位置。默认在系统临时目录下（如 `/tmp/v2o-console-data`），适合先试跑；正式用建议填一个固定的空目录。

填好后点**开始监听**。页面顶部状态变为运行中即可把视频放进视频文件夹。

## 3. 看进度

任务列表按“发现→听写→整理→成稿→入库”显示进度：

- 后台逐个处理，不用停留在页面等待。
- 点一行看笔记正文预览。
- 失败的行有点重试按钮，可单独重跑。
- 成功后可用“一键在访达中打开 / 在 Obsidian 中打开”。

支持的后缀：`.mp4` `.mov` `.mkv` `.m4a` `.mp3` `.wav`。

## 4. 词汇修正

术语、人名听错了：

1. 在**词汇**区加一行“错词→正词”。
2. 之后的新转写自动应用。
3. 已有的结果用重跑功能统一应用一次。

## 5. 笔记写到哪里

- 填了笔记库目录：按视频文件夹的相对目录结构镜像写入，源视频另外归档。
- 没填笔记库目录：只生成到数据目录，记为 `RENDER_ONLY`，这是正常结果，不是失败。

## 6. 停止与重起

- 前台按 `Ctrl+C` 停止服务。
- 服务重启后监听状态不会自动恢复，需要重新点**开始监听**。
- 页面记住了上次填的路径（浏览器 localStorage 为主），重开后一般会自动回填。
